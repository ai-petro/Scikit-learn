# 🛢️ Porosity-Permeability Prediction

Predicting reservoir permeability from porosity using Linear Regression.

## 📊 Project Details
- Model: Linear Regression (Scikit-learn)
- Input: Porosity (fraction)
- Output: Permeability (mD)
- Data: 100 synthetic samples

## 📈 Workflow
1. Generate synthetic well data
2. Crossplot visualization (Matplotlib)
3. Train/Test split (80/20)
4. Train Linear Regression model
5. Evaluate with MSE & RMSE

## 🛠️ Libraries
- NumPy
- Matplotlib
- Scikit-learn
